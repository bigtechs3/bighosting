# bighosting – Pterodactyl Server Store

A complete server selling website with SonicPesa USSD payment integration. Users can browse plans, pay via mobile money, and instantly receive Pterodactyl server credentials.

![bighosting](https://via.placeholder.com/800x400/0a0a0f/1a5276?text=bighosting)

---

## 🚀 Features

- **11 Server Plans** – From 1GB to Unlimited
- **SonicPesa Integration** – USSD push payments
- **Pterodactyl API** – Auto-create user + server
- **Instant Credentials** – Username, password, panel link sent immediately
- **Neon Theme** – Deep blue, grey, black & red
- **Matrix Rain Background** – Dynamic animated symbols
- **Audio Feedback** – Click and success sounds
- **Fully Responsive** – Works on mobile, tablet, desktop

---

## 📦 Tech Stack

| Layer | Technology |
| :--- | :--- |
| **Frontend** | HTML5, CSS3, Vanilla JavaScript |
| **Backend** | Node.js + Express.js |
| **Payment** | SonicPesa API |
| **Server Management** | Pterodactyl API |
| **Database** | JSON (upgradable to MongoDB/PostgreSQL) |
| **Deployment** | Render.com |
